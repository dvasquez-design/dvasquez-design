## 🚀 Featured projects

### 🔍 [cafe-cloudtrail-forensics](https://github.com/dvasquez-design/cafe-cloudtrail-forensics) — AWS Forensic Investigation
Simulated credential compromise on EC2 leading to IAM privilege escalation, investigated with CloudTrail, Athena, and Glue (partition projection). Includes a remediation script and a full walkthrough: deploy → compromise → investigation → teardown.
`AWS` `CloudTrail` `Athena` `IAM` `boto3` `Incident Response`

### 🌐 [three-htb-clone](https://github.com/dvasquez-design/three-htb-clone) — HTB Machine Replica on AWS
EC2 running nginx + php-fpm with a misconfigured S3 bucket (anonymous PutObject) mounted as the webroot, replicating a real Hack The Box machine's vulnerability as a self-hosted lab.
`AWS` `EC2` `S3` `nginx` `Pentesting`

### 🔐 [Vault Server](https://github.com/dvasquez-design/vault-server) — Personal Cloud Server
Self-hosted EC2 running Nextcloud + MariaDB via Docker Compose, exposed through a Cloudflare Tunnel (no inbound attack surface) and protected by Cloudflare WAF/DNS. Ongoing project: progressive hardening and an upcoming database migration to RDS.
`AWS` `Docker` `Cloudflare` `Self-hosting` `Hardening`

### 🧪 [HTB-writeups](https://github.com/dvasquez-design/HTB-writeups) — Hack The Box Machine Analysis
Technical write-ups on Starting Point machines (Meow, Fawn, Dancer, Redeemer), covering Telnet, FTP, SMB, and Redis, with methodology and findings explained step by step.
`Enumeration` `SMB` `Redis` `Pentesting`

### 💸 [Alke Wallet — Django + SQLite](https://github.com/dvasquez-design/Alke-Wallet-Django-CRUD)
Full-stack virtual wallet with a Django backend, authentication, and admin panel. Next step: migration to cloud infrastructure and a security-focused refactor.
`Python` `Django` `SQLite` `Authentication` `Refactor in progress`
