☁️ [CloudLab](https://github.com/dvasquez-design/CloudLab) — Hybrid Lab (on-premise + AWS)

First published: PentestLab, red team and blue team analysis of vulnerable VMs with a monitoring stack, starting with Mr. Robot. `AWS` `WireGuard` `CloudFormation` `KVM` `Pentesting`
