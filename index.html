Proyecto seleccionado

Alke Wallet — Migración a Django

El desafío más representativo de mi crecimiento técnico: migrar una app frontend estática a un sistema backend completo con base de datos real, autenticación y arquitectura escalable.

Módulo ABP Módulo 7 — Alkemy
Stack principal Python · Django · SQLite · Bootstrap
Repositorio github.com/dvasquez-design

📋 Descripción de la tarea

Migrar la Alke Wallet desde un frontend estático (HTML + Bootstrap + localStorage) a una aplicación web fullstack con backend Django, base de datos relacional SQLite, sistema de autenticación real y modelos que persisten los datos de manera profesional.

⚡ Desafío principal

El desafío central fue rediseñar la arquitectura completa: pasar de datos volátiles en localStorage a un modelo de datos relacional con tres entidades (Perfil, Contacto, Transacción) correctamente relacionadas, asegurando que cada operación financiera (depósito, transferencia) fuera atómica y consistente. Un desafío adicional fue garantizar que cada User tuviera siempre su Perfil asociado, independientemente del método de creación.

✅ Solución propuesta

  • Diseño de 3 modelos Django: Perfil (OneToOne), Contacto (ForeignKey) y Transaccion (ForeignKey + choices)
  • Signal post_save para creación automática de Perfil al registrar cualquier User
  • Uso de DecimalField para montos financieros (evita errores de punto flotante)
  • Protección total de rutas con @login_required y configuración de LOGIN_URL
  • Mapeo manual del tag error → danger en Bootstrap para mensajes flash
  • Tipificación de transacciones con TIPO_CHOICES para diferenciación semántica

🛠️ Herramientas técnicas utilizadas

  • Django ORM — modelado relacional, migraciones, signals
  • django.contrib.auth — autenticación, UserCreationForm extendido
  • Django Admin — list_display, list_filter, search_fields
  • Bootstrap 5.3 — UI responsive con Django Template Language
  • SQLite — base de datos persistente en desarrollo
  • Git + GitHub — control de versiones y documentación
